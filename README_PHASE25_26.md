# Cifria - Fases 25 y 26

## Fase 25 - Responsive y navegación móvil
- Menú móvil accesible con `<details>` sin depender de JavaScript.
- Objetivos táctiles mínimos de 44 px para botones y controles principales.
- Rejillas y tarjetas adaptadas a una sola columna en pantallas pequeñas.
- Tablas con desplazamiento horizontal controlado.
- Mejoras de legibilidad, wrapping y prevención de desbordamientos.
- Campos numéricos con teclado decimal en dispositivos móviles.

## Fase 26 - UX y refinamiento visual
- Jerarquía y espaciado refinados en móvil.
- Estados de foco visibles y consistentes.
- Controles de formularios más cómodos en pantallas táctiles.
- Resultados, tarjetas y bloques de metodología ajustados para lectura rápida.
- Soporte para `prefers-reduced-motion` mantenido.

## Validación
En esta entrega no se incluye `node_modules` ni `dist`.
Ejecutar en local:

```powershell
npm install
npm test
npm run build
```
